# Prayer magic effects

Keep editable source art for Prayer effects in this folder, grouped by specialization and element. Runtime particle atlases live in `textures/particle/prayer/` and are registered as five animated, emissive sigils: Divine, Unholy, Fire, Ice, and Lightning. Each atlas is a 4-by-4 PNG spritesheet with adjacent `.png.mcmeta` frame metadata; Minecraft renders the animation directly, so do not replace these with GIFs. Keep the 35 individual spell icons under `textures/gui/prayer/abilities/`, separate from in-world effects.
